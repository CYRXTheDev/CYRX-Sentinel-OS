# 🚀 CYRX ORBITAL OS

> A beginner-friendly browser-based WebOS inspired by astronomy and space exploration.

CYRX ORBITAL OS is a web-based operating system interface designed to simulate a simple desktop environment inside a browser.

The project combines a familiar operating-system experience with an astronomy-inspired visual theme, allowing users to interact with applications such as Notes, Explorer, Gallery, Terminal, and Settings.

## 🌌 About the Project

CYRX ORBITAL OS was created as a learning project for Stardance.

The main goal is to learn and practice real-world web development by building a project from the ground up using:

- HTML
- CSS
- JavaScript
- Git & GitHub
- Python (optional / future feature)

Rather than trying to build a real operating system, CYRX ORBITAL OS focuses on creating an interactive **WebOS-style environment** that runs directly in a web browser.

## 🎯 Goals

- Learn practical web development through project-based learning
- Practice HTML, CSS, and JavaScript
- Learn Git and GitHub collaboration
- Practice software development workflows
- Build an interactive WebOS-style interface
- Explore simple astronomy-related content
- Document our development process through Devlogs

## ✨ Features

### 🏠 Home

The main desktop environment and starting point of the OS.

### 📁 Explorer

A simple interface for browsing simulated files and folders.

### 🖼️ Gallery

A space-themed gallery for displaying images and visual content.

### 📝 Notes

A simple application for creating and managing notes.

### 🖥️ Terminal

A simulated terminal interface with basic commands.

### ⚙️ Settings

Basic system customization and configuration options.

## 🌌 Astronomy Theme

The project uses astronomy as its visual and educational theme.

Some of the topics included may include:

- 🌍 Earth
- 🌙 Moon
- ☀️ Sun
- 🔴 Mars
- ⭐ Stars
- 🪐 Solar System

The project does not attempt to provide advanced astronomical calculations or professional scientific tools.

Instead, astronomy is used as the inspiration for the interface and educational content.
